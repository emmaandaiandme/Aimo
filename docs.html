Getting Started

Quick Start

Get AIMO playing music in your server in under 60 seconds — no configuration needed.

Step 1 — Invite AIMO

Click the invite link and select your server. Grant the requested permissions — AIMO needs Connect, Speak, and Send Messages at minimum.

discord.com/oauth2/authorize?client_id=1466757680311042060…

Step 2 — Join a Voice Channel

Join any voice channel in your server. AIMO will automatically join the same channel when you run a music command.

Step 3 — Play a Song

Use the /play command followed by a song name or URL:

/play Starboy by The Weeknd # or use a direct URL /play https://open.spotify.com/track/…
AIMO shows a search results list so you can pick the exact version you want — no wrong remixes!

You're done!

AIMO is now streaming. Use the control commands to pause, skip, adjust volume and more. See Controls for the full list.

Playing Music

AIMO streams high-quality audio from multiple sources. Use slash commands to search, play, and control music in any voice channel.

Basic Playback Commands

/play [query]
Search for a song by name or paste a URL. Shows top 5 results to pick from.
Free
/pause
Pause the current track.
Free
/resume
Resume a paused track.
Free
/skip
Skip to the next track in the queue.
Free
/stop
Stop playback and disconnect AIMO from the voice channel.
Free
/volume [1-100]
Set the playback volume. Default is 50%.
Free
/seek [time]
Jump to a specific time in the current track. e.g. /seek 1:30
Free
/nowplaying
Show the currently playing song with progress bar and info.
Free

Loop Modes

/loop [mode]
Set loop mode: track (repeat current), queue (repeat all), off.
Free
/shuffle
Shuffle the current queue randomly.
Free
/autoplay
Toggle autoplay — keeps music going after the queue ends.
Free

How to Change Language
