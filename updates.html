v2.4 Latest 15 July 2026
AIMO Music — v2.4 Server Customisation Update
5 New Commands 2 Improved
New Features
  • Customise System — 5 new free commands: /customize-avatar, /customize-banner, /customize-nickname, /customize-reset, /customize-view. Set AIMO's avatar, banner, and nickname per server without premium.
  • Per-server scope — All /customize changes are isolated per server. Other servers see the default AIMO avatar and name.
Improved
  • /help command updated — Customise category added with all 5 commands listed and described.
  • Admin permission check — /customize commands now require the Manage Server or Administrator permission to prevent unauthorised changes.
Have questions? Join the support server

AIMO Music — v2.3 Stability & Intelligence Update
2 New 3 Fixed
New
  • AI knows what's playing — /ask now sees the current song, artist, volume & queue in real time. Try "what song is this?"

Fixed
